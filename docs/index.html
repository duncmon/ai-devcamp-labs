Site Architecture & Navigation Philosophy

Read Full Architecture Philosophy →

Why Two Distinct Visitor Trips? Rather than compressing the instructor's tutorial narrative and the attendee's technical dissection into an unwieldy side-by-side layout, this site treats them as two parallel, standalone tracks. Each page gives the reader complete, uninterrupted immersion in its respective context.

The Universal 1-Click Companion Bridge: Every lab page features a persistent companion button in its navigation header. When reading the instructor guide for Lab 2, Duncan's Lab 2 walkthrough is exactly one click away. When reading the attendee post-mortem for Lab 2, Sonika's original notes are one click away.

Running locally: cd docs && python -m http.server 8080, then open localhost:8080 (or localhost:8080/instructor/).
